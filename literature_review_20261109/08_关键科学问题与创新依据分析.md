# 关键科学问题与创新依据分析

## 一、判断规则

本报告不使用“首次”“填补空白”“尚无研究”等绝对表述。对每个候选关系给出五级证据状态：

1. **已有直接车联网研究充分涉及**：A/B类论文已在同一模型/约束中处理该关系；
2. **已有直接车联网研究部分涉及**：A/B类论文处理了其中一部分变量，但未形成该联合关系；
3. **仅在通用MEC中存在相近机制**：C/D类论文有相近机制，不能直接作为车联网证据；
4. **尚未找到直接证据**：本地语料中未检索到该联合关系，但不等于领域不存在；
5. **现有证据不足，暂不能判断**：全文/模型/实验尚未核清，或论文只给了摘要级信息。

## 三、哪些说法不能再用

1. “现有研究没有自适应更新机制”——错。L084、L134、L008、L103 都有不同程度的更新/重部署/保持决策。
2. “现有研究没有逐任务时延预算/队列反馈”——错。L084 有逐任务 budget、超预算比例、等待工作量；L005 有真实队列；L049 有超时失败代价。
3. “现有研究没有联合服务部署和任务卸载”——错。L001、L067、L079、L083、L101 等已联合。
4. “现有研究没有考虑UAV轨迹”——错。L037、L048、L053、L114、L134 等都有 UAV 轨迹/移动。
5. “现有研究没有迁移与资源协同”——错。L029、L080、L094、L115 等已联合。
6. “现有研究没有服务连续性/状态同步/回退”——错。L087、L080、L004 已有预迁移、状态同步、暂停/恢复；回退机制需具体核对，但不能笼统说没有。
7. “现有研究没有多业务/QoS”——错。L005、L049、L117、L133 等都有。
8. “现有研究都是固定部署/固定周期”——错。L008 按需重部署、L103 保持/替换、L134 变间隔、L084 自适应更新开关。
9. “用了Lyapunov/P-DQN/DRL就是创新”——不成立。方法本身不是贡献，必须落到决策关系/约束/可行性条件。
10. “轨迹预测+服务迁移就是创新”——不成立。L069、L087、L124 等已做预测辅助迁移/目标选择。

## 四、哪些关系仍有较强证据支撑

按当前本地语料，**相对更有证据支撑**（仍需正式模型确认）的是：

1. **C4 预测误差—迁移窗口—迁移带宽/正常任务传输的联合可行性**：组件在 L029/L080/L087/L004 分别出现，但未在同一决策中闭合；直接VEC中尤其缺少“窗口”与“同步进度”的显式约束。
2. **C1 配置保持时间—剩余时限—资源可行性的联合**：L084 的预算反馈、L001 的移动链路驻留、L014 的双时标分别接近，但没有一篇把“配置保持期间任务能否被接纳”写成约束。
3. **C6 业务构成/流量/信道三类变化的分离作用**：L005/L049 分别处理了业务比例/类型，L101/L086 处理了在线部署，但“三类变化分别参数化并共同作用于服务部署需求与资源供给”尚未在直接VEC中看到。
4. **C7 长期效用/调整成本/队列积压的联合**：三个要素分别有强近邻，但同一VEC模型中的联合仍需证明。

## 五、哪些方向需要缩小范围

1. **P1 不要以“部署周期自适应”为核心**。L134 已把更新间隔作为动作；L084 已有自适应更新开关。P1 应缩到“配置保持时间与任务剩余时限的可接纳性 + 快层反馈”。
2. **P2 不要以“轨迹预测辅助迁移”为核心**。L069/L087/L124 已有；P2 应缩到“预测误差如何改变窗口，迁移带宽如何同时影响同步进度与正常任务传输”。
3. **P3 不要以“多业务+Lyapunov”为核心**。L005/L049/L101 已有；P3 应缩到“业务构成/流量/信道三类变化的分离作用 + 部署调整成本/队列/长期效用”。
4. **不要把“服务下载/启动/就绪”写成已有模型**。正式研究内容和方案没有定义该状态；只有在补充模型后才能主张。
5. **不要把切片激活、内容缓存、服务程序放置、服务实例部署混为一谈**。四者在 L049、L103、L101、L080 中分别是不同对象。

## 六、建议的下一步（建模前）

1. 为P1写出“配置保持时间—任务剩余时限—可接纳性”的约束草案，明确任务在配置变化期间被拒绝/排队/转移的处理。
2. 为P2写出“预测误差→候选目标/窗口→迁移带宽/同步进度→正常任务传输”的约束链，明确窗口终点和回退条件。
3. 为P3写出“业务构成、同类流量、信道”三类参数及其对服务部署需求/带宽/CPU/队列的分别作用，避免只用聚合负载。
4. 对每条候选关系做“最近邻反证”：若某篇论文已覆盖，则删除或收窄；若只有通用MEC覆盖，则明确领域差异，但不能把通用机制直接当车联网证据。
