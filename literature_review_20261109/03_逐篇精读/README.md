# 逐篇精读目录说明

本目录按领域分为五个子目录：

- `直接车联网/`：A类，实际研究场景为 IoV/VEC；
- `空地协同车联网/`：B类，存在实际车联网场景且使用 UAV/AAV；
- `通用MEC/`：C类，通用 MEC/边缘计算；
- `通用UAV-MEC/`：D类，通用 UAV-MEC，无车联网场景；
- `其他相关研究/`：E类，海事、WAN、云迁移、控制理论等。

共138个与 `01_文献分类总表.csv` 对应的笔记文件。每篇笔记开头都写明阅读状态：

- **全文精读完成**：作者信息、系统模型、优化问题、求解方法、仿真/结果、作者局限与阅读者局限、三个研究点关系、原文页/式/图索引均已核对；共33篇。
- **筛查稿**：全文文本已提取，完成了章节定位、分类、关键词命中和证据片段摘录，但未逐页逐式核对；共104篇。筛查稿不计入“全文精读完成”。
- **无法提取全文**：L091，PDF流损坏，未用摘要替代；共1篇。

筛查稿的作用是让全库可检索、可复核，不是把“未读到”写成“论文未考虑”。凡涉及“某文未考虑某机制”的判断，必须在深读稿或原文页/式定位中找到依据；仅有筛查稿时只能写“尚未核对/尚未找到”。

逐篇笔记的文件名尽量采用规范题名；同一编号只保留一个文件（深读稿优先于筛查稿）。原始 PDF 未删除、未修改路径。
