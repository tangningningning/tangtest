# L039 — Deep Reinforcement Learning-Based Task Offloading for Vehicular Edge Computing With Flexible RSU-RSU Cooperation

## 1. 基本信息与阅读范围
Wenhao Fan、Yaoyin Zhang、Guangtao Zhou、Yuan'an Liu；2024；IEEE Transactions on Intelligent Transportation Systems 25(7):7712–7725；DOI 10.1109/TITS.2024.3349546；14页。已读 PDF 第1–14页正文（摘要、II相关工作、III系统模型与问题、IV TD3算法、V实验、VI结论）。核对式(1)–(47)、图1–9、表I–III的标题与正文引用；表II、表III的参数数值为图片，未核。

## 2. 背景、问题与作者思路
【作者表述】车辆高速移动会使任务结果在车辆驶出原RSU后无法接收；热点与冷区并存造成RSU负载不均；已有RSU-RSU协作不够灵活——要么任务只能卸载到原RSU、结果可转发，要么任务可卸载到任意RSU、结果必须回原RSU（p.1–3）。本文让任务卸载到任意RSU k计算、结果再经R2R转发到车辆当前所在RSU l，联合优化任务卸载、车辆/RSU算力、V2R功率与R2R速率（p.3）。
【阅读判断】技术对象是"任务卸载+结果路由"，β的三重下标(j,k,l)正是"源RSU—计算RSU—结果接收RSU"。文中没有服务实例、镜像或状态迁移；所谓flexible cooperation是任务重卸载与结果重路由，不能读成服务迁移。

## 3. 系统模型与对象
M个互连RSU，各配一个ES；RSU j 初始覆盖 N_j 辆车（p.3）。任务建模为三元组<c, d_in, d_out>；α=1本地执行，β_{ijkl}=1表示任务从车 i_j 经RSU j 转到RSU k 计算、结果经RSU l 回传；l 只能取 {j, ξ}，ξ 为行驶路径上的下一个RSU（p.4）。χ 为车辆相对原RSU j 的驻留时间（holding time）。接入为OFDMA，V2R/V2V用SINR与香农速率(9)–(15)；R2R为有线连接，总速率 R^r2r_j 按连接分配 r^r2r_jk (16)。能耗只计本地计算 κf²c (19) 与V2R发射 p·t (20)；RSU计算能耗与R2R传输能耗未计入。无内容/镜像缓存，无服务可用性约束，默认任一RSU都能执行任一任务。

## 4. 优化问题：目标、变量、约束
P1：min_{A,B,F^v,F^r,P,R} u，s.t. C1–C12（(30)–(31)）。u 为所有车辆任务处理成本之和，成本=时延+w·能耗，按五种情形分段(21)–(29)。离散变量：α、β（β为三元组，组合数约 M³）；连续变量：车辆算力 f^v、RSU算力 f^r、V2R功率 p、R2R速率 r。约束逐项：C1/C2取值域(1)(2)；C3每任务只选一种方式(3)；C4/C5算力上限(4)(6)；C6 RSU算力总和(7)；C7功率上限(10)；C8 R2R速率上限(16)；C9–C12为驻留时间约束(22)(24)(26)(28)——情形2、4要求完成前不驶出原RSU，情形3、5要求完成时已进入下一RSU。单次决策、单任务，无跨时隙耦合与队列。

## 5. 求解方法
P1为MINLP：变量离散连续混合、目标非凸、C9–C12非凸（p.6）。解法是分解+TD3：先固定卸载决策，SP1求车辆算力，闭式解 f=1/(3√(2wκ)) 并投影到上限（算法1，p.7）；SP2求发射功率，判定为准凸后用Dinkelbach求最优(33)；剩余部分（A、B、F^r、R）建MDP，状态={任务剖面, 下一RSU与驻留时间, 无线参数}(34)，动作={A,B,F^r,R}(35)，奖励 r=−u 加违约惩罚(36)–(40)，用TD3（双评论家、目标平滑、延迟更新）求解。C1–C8用tanh/softmax硬约束，C9–C12仅以惩罚进入奖励，故最终策略不保证可行。复杂度 O(ΣY_iY_{i+1}+2ΣN_j+ΣW_ij)，Dinkelbach迭代1–4次、均值2.81（p.10）。非精确MIP，也无收敛证明。

## 6. 仿真实验
用意大利博洛尼亚工作日8:00–9:00的车辆轨迹数据集（22,000余辆、1s采样）计算 ξ 与 χ（p.10）。RSU数3–7；高负载RSU 0–4个（每个50辆车），总RSU数5–9；6类参数在默认值50%–150%间变化；每次50次独立仿真。基线：TRTO（只允许结果转发）、RTOO（只允许任务转卸载）、ECRA（算力均分）、FTPA（固定最大功率）。指标为总成本 u、RSU负载、收敛。结果：总成本较4个基线降低17.3%–28.4%（p.10–11）；TD3约280回合收敛，DDPG约420，DQN 500回合内未收敛（p.10）；启用负载转移后RSU 1–4与5–9的负载差缩小（图6）。表III具体参数值未核。

## 7. 作者明确指出的局限
原文没有 limitation 或 future work 段落。结论(p.13)只总结方法与"优于4个参考方案"，未讨论驻留时间预测误差、惩罚式约束的可行性或RSU算力能耗建模缺失。故本节记"无"。

## 8. 阅读者发现的潜在局限
(1) χ 与 ξ 直接由数据集轨迹离线算出，等价于已知未来轨迹，未讨论预测误差（p.10）。(2) 结果接收RSU只允许原RSU或下一RSU（l∈{j,ξ}），而任务可去任意RSU，两者不对称（p.4）。(3) C9–C12以奖励惩罚实现，训练后策略仍可能违反驻留约束，文中未统计违约率（p.8）。(4) 时延只含传输与计算，未建模RSU任务队列；多任务共享 f^r 但无排队（(8)）。(5) 无服务缓存/镜像可用性约束，等价于假设所有RSU具备所有服务能力，因而不能支持"服务部署"结论。(6) 能耗式(19)(20)不含RSU计算与R2R传输能耗，成本口径偏窄。

## 9. 与三个研究点的关系
P1：剩余时限——已覆盖，χ 作为硬时限写入C9–C12，但依赖已知轨迹；配置保持——未涉及；快慢反馈——未涉及，单次决策无跨时隙反馈。
P2：预测误差——未涉及；迁移窗口——部分，驻留时间窗口用于任务结果而非迁移；传输竞争——部分，OFDMA共道干扰与R2R速率分配已建模，但无多用户调度竞争。
P3：业务构成——部分，任务用<c,d_in,d_out>与权重 w 区分，无QoS类；流量——未涉及，无到达过程；信道——部分，SINR与共道干扰；在线部署——部分，算法部署在连接所有RSU的控制器上（p.9 §IV-D），但实验为离线仿真。
