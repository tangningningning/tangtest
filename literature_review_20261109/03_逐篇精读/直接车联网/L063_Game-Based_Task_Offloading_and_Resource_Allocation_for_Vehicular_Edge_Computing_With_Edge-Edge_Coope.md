# L063 — Game-Based Task Offloading and Resource Allocation for Vehicular Edge Computing With Edge-Edge Cooperation

## 1. 基本信息与阅读范围
Wenhao Fan、Mingyu Hua、Yaoyin Zhang、Yi Su、Xuewei Li、Bihua Tang、Fan Wu、Yuan'an Liu，2023，*IEEE Transactions on Vehicular Technology* 72(6):7857-7870，DOI 10.1109/TVT.2023.3241286，14页。本次读 PDF 第1—13页正文与附录A/B（第12—13页），核对式(1)—(37)、约束C1—C11、算法1—3、表1—表4、图1—11；表3的具体参数值在提取文本中只留表头，**参数数值未核实**；参考文献未逐条读。

## 2. 背景、问题与作者思路
【作者表述】多 RSU 场景下车辆地理分布不均导致边缘服务器负载失衡，热点 RSU 过载；利用 RSU 间高速光纤（FiWi）互联做边缘—边缘协作，可把热点 RSU 已卸载的任务再转给低负载 RSU（第1页）。作者联合优化部分卸载比例、信道分配与 RSU 间负载均衡，目标是最小化所有车辆的总任务处理时延，同时保证每车时延容忍度与驻留时间（holding time）（第1—2页）。
【阅读判断】核心是**任务重卸载/任务重路由**（task re-offloading between RSUs），不是服务实例迁移：被转移的是已卸载任务的计算量，源 RSU 不保留服务实例，也无状态同步。

## 3. 系统模型与对象
N 个 RSU 各带一个边缘服务器，全部经 LAN 互联；每 RSU 覆盖一条双车道直线路段，覆盖半径 200—300 m；车以恒定速度 v_mn 沿直线行驶，位置由式(1) 给出（第2—3页）。每车任务为 Poisson 到达（速率 λ_mn），任务属性为数据量 d_mn、计算密度 η_mn、时延容忍 T_tol_mn（第3页）。卸载采用**数据分割的部分卸载**：α_mn∈[0,1] 为卸载比例，本地与边缘串行执行（第3页，C1）。RSU 间再用二值变量 β_mni 决定是否转给另一个 RSU，且最多转一次、不可再分割（C2、C3，第4页）。通信为 OFDMA，每 RSU 有 W 个等带宽信道，车与信道一一匹配（C6—C8），存在跨 RSU 同频干扰（式(13)(14)，第4页）。排队：车与 RSU 均为 M/M/1（式(3)(6)），LAN 传输也为 M/M/1（式(18)）。**对象只有任务与计算/通信资源**：无内容缓存、无镜像/服务实例、无存储节点、无状态同步、无接入切换建模；"holding time" 只是通信覆盖窗口。

## 4. 优化问题：目标、变量、约束
P1（式(25)，第5页）：min_{α,β,γ} t=Σ_nΣ_m t_mn，其中 t_mn=t_veh+t_rsu+t_v2r+t_r2r（式(21)）。变量：α 连续、β 与 γ 二值，故为 MINLP。约束逐项：C1 卸载比例∈[0,1]；C2 β 二值；C3 每车最多转给一个 RSU；C4/C5 本地与 RSU 队列稳定（到达计算量<算力）；C6—C8 信道分配互斥；C9 LAN 排队稳定；C10 总时延≤时延容忍；C11 卸载部分时延≤驻留时间（式(22)(23)）。时间尺度是**单快照静态优化**，靠外层迭代逼近，不是显式快慢两层。

## 5. 求解方法
建模：M/M/1 排队 + 部分卸载 + 势博弈。算法为两阶段迭代（算法3，第8页）：阶段1 解 TOCA——固定 β、γ 后对 α 的子问题 P2 被论证为凸，用内点法，复杂度 O(|α|³)；信道子问题 P3 为非线性的二值匹配，用"固定干扰—逐 RSU 匈牙利匹配—全局更新干扰"的启发式（算法1），复杂度 O(W³log(...))。阶段2 解 RLB——把 RSU 间转发放进**精确势博弈**，构造势函数（式(34)）证明势博弈性质（附录A，式(33)(35)(36)）与 NE 存在（附录B），用分布式 DRLB（算法2）迭代至 NE，单 RSU 复杂度 O(π(M_n+N))（第7—8页）。**不是精确 MIP**：作者明确说穷举最优不可行，两阶段只给次优解（第5页）。

## 6. 仿真实验
7 类场景、8 组参数扫描：RSU 数 3—8（图3）、高负载 RSU 数 1—5（每 RSU 50 车，图4）、边缘算力 20—40 G cycles/s（图5）、车辆算力 2—4.5 G cycles/s（图6）、信道带宽 10—30 MHz（图7）、任务数据量 10—20 MB（图8）、时延容忍（25% 车辆从 1.5 s 到 4 s，图9）、驻留时间 1—3.5 s（图10）；每场景 200 次平均，路径损耗 128.1+37.6lg d、阴影 8 dB、Rayleigh 快衰落（第9页）。基线：BOCA、POCA、BORLB、PORLB（第9页）。结果：本文方案在全部扫描中总时延最低，且负载越重优势越大；开启负载均衡后各 RSU 工作量趋于相等（图11）；收敛迭代数：算法1 为 2.1—3.3、算法2 为 2.4—4.1、内层 3.8—9.1、外层 3.1—6.5（表4，第11—12页）。原文只给曲线，**无绝对时延数值**。

## 7. 作者明确指出的局限
结论（第12页）未列局限或未来工作，只重述方法。正文中明确承认的只有：P1 是 MINLP、穷举最优复杂度过高不可行，所提两阶段算法得到的是**次优解**（第5页）；控制信息传输时延被忽略（第8页末尾）。

## 8. 阅读者发现的潜在局限
(1) 约束 C10、C11 印为 t_mn ≤ λ_mn·T_tol_mn 与 t_off ≤ λ_mn·T_hld_mn（式(22)(23)，第5页），左侧是秒、右侧是"任务/秒×秒=任务"，**量纲不一致**，疑为排版/推导笔误；若按字面理解，时延约束随到达率放松，结论会失真。(2) 车辆恒速直线、位置解析式(1)，无换道/加减速/预测误差（第2—3页）。(3) 只有一跳 RSU-RSU 转发且不可再分割（C3），大规模热点下负载均衡能力受限。(4) 目标只含时延，无能耗、无迁移/传输的带宽成本（式(24)(25)）。(5) 信道分配是启发式，未给相对最优的间隙；两阶段交替也未给全局次优界（第5、7页）。(6) 表3 参数值缺失，复现性受限。(7) 图3—11 无绝对数值，提升幅度不可引用。

## 9. 与三个研究点的关系
- **P1 配置保持/剩余时限/快慢反馈**：部分。有明确的**时延容忍**与**驻留时间**双约束（C10、C11），是所有样本中最接近"剩余服务窗口"的建模；但没有服务配置/更新周期，也没有慢快两层时间尺度与反馈，仍是单快照优化。
- **P2 预测误差/迁移窗口/传输竞争**：部分。驻留时间 T_hld 构成天然的"服务窗口"，且 RSU-RSU 转发需经 LAN 排队（式(18)），体现了传输竞争；但移动是确定性恒速，无位置预测、无预测误差，也无迁移窗口的时机优化。
- **P3 业务构成/流量/信道/在线部署**：部分。信道有 OFDMA 跨 RSU 同频干扰与 SINR（式(13)(14)），任务到达为 Poisson；但业务只有单一任务类型、无业务构成与非平稳流量，部署是离线仿真而非在线系统。

## 10. 可复用证据与不能说的话
可复用：多 RSU 边缘—边缘协作做**任务重卸载**的完整模型与势博弈求解（第4—8页）；"驻留时间约束"作为卸载可行域的写法（C11，第5页）；两阶段分解与收敛迭代数（表4）。不能说的话：不能说该文做了服务实例迁移、镜像预部署或状态同步；不能把 β 的 RSU 间转发放进"服务迁移"文献队列；不能引用其"显著降低时延"的具体百分比（原文无绝对值）；不能把 C10/C11 当作可直接复用的正确公式，需先修正量纲。
