校准预测为正式 stochastic collector 在每 Slot 动作前记录的 `old_value = V(s_t)`；逐 Slot reward 来自正式 `execute_configured_slot()` 链路。MC RTG 按 episode 从实际 300 个 reward 反向计算：`G_t = r_t + gamma * G_(t+1)`，terminal 后置 0；配置 gamma=1，因此是不折扣的同 Episode 后缀 reward 和，不跨 Episode bootstrap。

`gae_lambda_return` 是正式 `compute_gae()` 输出的 `advantage + old_value`，配置 `gae_lambda=0.95`；它是 lambda-return Critic target，不等于 MC RTG。两种 target 的误差分开呈现。Value Bias 定义为 `mean(V−target)`，正值为预测偏高；EV=`1−Var(V−target)/Var(target)`。方差采用总体定义，与 Trainer 的 explained-variance 口径相同。

## 结论与限制

- **是否有系统性 Value 偏差：** 在本次两个独立 stochastic Validation seed 的样本中，有清晰的时段性偏差模式：两 Checkpoint 的 MC RTG Bias 在前/中段均为负（低估），后段均为正（高估）。例如 5e-4 为 −324.6 / −122.1 / +60.4，1e-3 为 −425.3 / −122.5 / +100.0。整体 Bias 仍为负（−128.8 / −149.3），但全段聚合掩盖了后段过估。整体 EV 为 0.911 / 0.914；前段 EV 降至 0.200 / 0.667。就这些采样轨迹而言，这支持“Value 校准随剩余 Episode 时长系统变化”的描述性判断，不足以证明更广泛 Validation 分布上的稳定偏差。
- **与 Critic 训练 target 的区别：** 对 GAE lambda-return 的整体 Bias 约 −29.8 / −29.3，EV 为 0.986 / 0.992；这优于 MC RTG 校准，尤其不能以 lambda-return 高 EV 代替真实 MC 校准。GAE lambda-return 由旧 Value 自身参与构造，target 更接近预测值是预期属性。
- **是否支持偏差影响 UAV 学习：证据不足。** normalized Advantage 表显示强烈的时段变化；同段 STAY/MOVE 组的差异较小或不一致，但组状态分布不同。PPO actor 梯度使用 normalized Advantage 与动作 log-prob 梯度的乘积；目前没有按相同状态配对的 Critic 残差—动作梯度分析，无法把上述时段偏差归因到 MOVE 被抑制/促进。它是需要关注的潜在 GAE 信号来源，不是已证实的 UAV 动作根因。
- 每 Checkpoint 只有两个 independent Validation seed，分段各 n=200（来自两个 Episode）；报告不做显著性推断，也不比较训练进度不同的 5e-4 / 1e-3 学习率效果。此处结果是 stochastic Critic 校准，与确定性泛化 Return 完全分开。
- 逐 Slot 校准统计已写入本报告；临时原始记录在报告生成后删除。Checkpoint SHA、模型参数和 optimizer counters 在采集/分析前后核对不变。
