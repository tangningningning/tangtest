# B3-15E：Cache候选收益空间与Actor选择差距诊断

## 结论摘要

- `VALID_PAIRED_STATES = 12`，三个Training Seed各取4个预先指定锚点附近最近的真实Macro边界。12个PPO实际动作分支均逐Slot复现参考Rollout，数值容差为`1e-10`。
- 有限预选集合包含270个非KEEP配置（包含PPO实际联合动作）和12个ALL_KEEP基线。26/270个非KEEP配置的实际净收益为正，分布在8/12个状态；正收益候选全是单节点UPDATE。有限集合不等于完整合法动作空间。
- PPO实际采样的联合Cache动作在12/12个状态均比ALL_KEEP收益低，平均`ΔReturn = -0.299491`。每个状态中，预选集合的最佳动作均优于PPO实际动作，平均差距`+0.507716`。
- 36个双节点变更配置没有一个获得正净收益。另有一个实际采样的单节点目标单独评价时为正，但同一帧的PPO联合动作包含另外两个UPDATE，整体仍为负。这支持“本样本中联合更新成本/组合选择抵消了个别节点收益”的解释，不足以证明总体PPO策略失效。
- 三个Holding恰为3 Slot的状态提供了可比预测时域。预测候选的任务效用排序有一定一致性，但样本只有3个状态；净收益分类出现6个假阳性。不能据此认可预测门控，也没有证据显示普遍存在预测效用低估。

整体上，最佳有限候选相对KEEP的均值为`+0.208225`（范围`-0.041091`至`+0.639311`）；最佳有限候选相对PPO实际联合动作的收益差均为正，均值`+0.507716`（范围`+0.095983`至`+1.011125`）。这不是全局最优差距，因为候选集有限且没有枚举所有合法Cache配置。

PPO实际联合动作相对KEEP的平均分解为：`ΔTask Utility = +0.000367`，`ΔCache Cost = +0.299858`，`ΔUAV Cost = 0`，因此`ΔReturn = -0.299491`。固定UAV轨迹使UAV成本差为零。个别状态的任务效用变化可正可负，但平均收益增量不足以抵消Cache变更成本。

在Seed 20021、Slot 40，SV节点19的实际采样单节点目标单独执行时，`ΔTask Utility = +0.145311`、`ΔCache Cost = +0.099496`、`ΔUAV Cost = 0`、`ΔReturn = +0.045815`；其同帧PPO联合动作包含3个节点更新，整体`ΔReturn = -0.120341`。该单节点目标在预选候选的Actor联合概率排序中为12/25，故并非策略概率最高目标。此案例显示节点收益会被联合动作构成改变；不能把该单节点收益直接加总或外推为联合收益。

有限集合中的36个双节点变更配置全部没有正净收益；可与其组成单节点动作比较的交互残差均值为`-0.003908`，范围`[-0.042706, +0.004707]`。这组预先规定的组合未显示有益协同，但不代表其他节点组合不存在协同。

## Actor排序与候选机会

PPO实际联合动作在本次有限候选的策略概率排序中，11/12排最后；剩余一个为20/23（从高到低排名，第四低）。26个正收益候选的排序为6–23，均值14.12/每状态22–25个可排序候选。排序仅针对本次评估的有限合法配置。训练动作是随机采样，实际抽到一个低概率联合组合并不能单独证明Actor的确定性排序错误或训练实现有Bug。

26个正收益候选中，16个带有预测需求推荐来源，9个为Actor条件Top UPDATE，1个是PPO实际采样的节点目标。四个状态的有限候选集没有正收益动作；在这些状态中最佳候选仍为轻微负收益（`-0.005162`、`-0.010000`、`-0.010000`、`-0.041091`）。因此，候选集对多数状态发现了局部机会，但其余状态可能没有当前预选目标的净收益空间，也可能遗漏未枚举的有益动作；本实验不能区分这两种情况。

## 预测收益排序（探索性）

预测效用以决策时可访问的4个预测场景、3 Slot窗口计算，使用相同的预测任务与决策时UAV位置；真实反事实使用实际任务轨迹和实际Holding时长。实际Holding为1、2或4 Slot的9个状态与预测窗口不等长，不能把差值解释成纯预测误差。只有3个Holding为3 Slot的状态共67个候选配置可进行同长度对照。

在这67个配置中，预测`ΔTask Utility`相对实际`ΔTask Utility`的平均偏差（预测减实际）为`+0.005598`，MAE为`0.075296`；31个低估、31个高估、5个近似相等。每个状态内部的候选效用排序有473对一致、198对不一致、48对含并列；排除并列后方向一致率为70.49%。因此该小样本没有显示普遍的预测效用低估，排序表现也不完美。

以预测`ΔTask Utility − 正式Cache成本`判断净收益，在同一67个候选中得到5个真阳性、6个假阳性、0个假阴性、56个真阴性。形式上的5/5正收益召回仅基于3个状态和5个正样本，不是可靠的召回率证明；6个假阳性也说明预测为正不保证实际净收益为正。此结果不能支持把预测门控投入生产，也不应再据此调门槛。

**`PRIMARY_NEXT_FIX`：优先研究成本感知的稀疏联合Cache动作协调。** 当前证据指向多节点同时重配置的成本经常大于任务效用增量，而少量单节点UPDATE能带来正收益。下一步应先在离线副本验证“选择哪些节点共同更新”的一致目标与策略概率设计；不能在PPO采样之后直接把UPDATE改成KEEP并仍使用原动作Log-Prob训练。当前不修改生产算法。
