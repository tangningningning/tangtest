## 联合效应分解

- 实际联合动作相对 all-KEEP 的两 Slot 任务效用变化为 `-0.145206`，Cache 成本增加 `0.122341`，UAV 成本不变；两 Slot 折扣净效用变化为 `-0.267547`。
- 四个单节点分支的任务效用变化之和为 `-0.138274`；其 Cache 成本之和恰为 `0.122341`。因此，两 Slot 实际净效用的联合交互项（联合变化减单节点变化之和）为 `-0.006932`。
- 四个单节点有限期 ΔQ 之和为 `-0.006701`，联合有限期 ΔQ 为 `-0.019371`，有限期 Q 交互项为 `-0.012670`。其中冻结 Critic bootstrap 本身也有非加性差异；因此不应把该 Q 交互项直接解释为真实长期耦合损失。
- 联合分支低于最佳单节点有限期 Q（节点 0 单独更新）约 `0.469360`，但该差距主要来自同时包含了节点 1、6、8 的负单节点有限期 ΔQ；节点 0 单独更新的两 Slot 实际净效用仍比 all-KEEP 低 `0.020000`，其正 ΔQ 来自冻结 Critic bootstrap 的提升，不是已观测到的两 Slot 实际收益。

分支结束后，Trace 摘要校验、全局及 Trainer/Micro RNG、策略参数和环境上下文指纹均未变化；动作合法性与候选索引映射检查通过。没有访问 Validation/Test，没有训练或执行完整 Episode。

## 判断

**本样本未显示足以优先实施九节点联合决策机制的强耦合证据。** 联合有限期 Q 相比单节点 ΔQ 之和的额外损失为 `0.012670`，两 Slot 实际净效用交互项为 `-0.006932`，而 Cache 成本严格相加。联合动作的负结果更多地对应若干单节点选择本身的负有限期 ΔQ，而非显著的组合非线性；同时，节点 0 的正有限期 ΔQ 受冻结 Critic bootstrap 影响，实际两 Slot 净效用并未改善。

因此，当前不建议仅凭此样本开发联合 Cache 协调机制。更值得回到**单节点 Candidate/Trigger 选择质量与冻结 Critic 有限期价值估计和实际短期收益的一致性**。这一结论仅适用于该 Training 状态；节点交互在其他状态是否更强仍未确定。未扩大样本或启动后续实验。
